# meteor-ch-tui

基于 Go 和 Bubble Tea 的 ClickHouse 终端客户端，支持连接管理、查询、历史记录以及连接配置/查询结果的导入导出。

## 功能特性

- 连接管理：新建、编辑、删除、分组、测试连接，支持批量标记、批量移动分组与批量删除。
- 查询：SQL 编辑、结果表格、查询历史、右键菜单、列显示/隐藏与列宽设置。
- 复制与导出：
  - 查询结果：TSV、CSV、JSON、XLSX。
  - 连接配置：JSON、CSV、TSV、XLSX。
  - `Ctrl+Y` 直接复制查询结果 TSV。
- 导入：
  - 粘贴 JSON、CSV、TSV。
  - 文件浏览器选择 `.json`、`.csv`、`.tsv`、`.xlsx`。
  - Excel 多工作表时可选择工作表。
- 文件浏览器：支持 `/` 搜索、`s` 切换名称/修改时间排序。
- 路径输入：支持 `~`、`$VAR`、`%VAR%`，留空表示当前目录。
- 目录记忆：跨进程记住最近使用的导入/导出目录。
- 应用内按 `?` 或 `F1` 打开快捷键帮助。

## 安装与运行

需要 Go 1.26 或更高版本。

```powershell
go build -o meteor-ch-tui.exe .
./meteor-ch-tui.exe
```

查看版本：

```powershell
./meteor-ch-tui.exe -version
```

## 构建

Windows 本地构建：

```powershell
./build.ps1
```

构建到指定文件：

```powershell
./build.ps1 -Out meteor-ch-tui-next.exe
```

构建全平台产物到 `dist/`：

```powershell
./build.ps1 -All
```

## 快捷键

### 连接管理器

| 按键 | 功能 |
| --- | --- |
| `↑` / `↓` | 选择连接 |
| `Enter` | 连接 |
| `+` | 新建连接 |
| `e` | 编辑连接 |
| `空格` | 标记 / 取消标记当前连接（列表显示 `[x]`） |
| `Ctrl+A` | 全选所有连接 |
| `m` | 将标记的连接批量移动到分组 |
| `Del` / `Backspace` | 删除连接；有标记时批量删除所选 |
| `g` | 分组管理 |
| `Ctrl+T` | 新建/编辑弹窗中测试连接 |
| `Tab` / `Ctrl+I` | 导入连接配置 |
| `Ctrl+E` | 导出连接配置 |
| `?` / `F1` | 快捷键帮助 |
| `Ctrl+C` | 退出 |

| --- | --- |
| `Tab` / `Shift+Tab` | 切换焦点 |
| `Ctrl+N` | 打开连接配置 |

| `Ctrl+R` | 读取活跃查询 |

## 数据与配置位置

- 连接配置：`~/.meteor-ch-tui/config.json`
- 界面状态（最近导入/导出目录）：`~/.meteor-ch-tui/ui-state.json`
- 导出文件默认写到当前目录，也可在弹窗中指定。

连接配置导出默认脱敏密码为 `<redacted>`；导入时若使用该占位符，会保留已有密码或留空。导出弹窗按 `Tab` 开启「包含密码」时会弹出安全提醒，确认后才会写入明文密码，请妥善保管导出文件。

连接配置文件以仅当前用户可读写的权限保存（目录 `0700`、文件 `0600`，Windows 下以系统 ACL 为准）。

连接密码存储在系统密钥环中，不写入 `config.json`（文件里仅保留 `<stored-in-keyring>` 占位符）：Windows 使用凭据管理器，macOS 使用钥匙串，Linux 使用 Secret Service。旧版配置中的明文密码会在首次加载时自动迁移到密钥环。若系统密钥环不可用（如无头 Linux 环境），会降级为在 `config.json` 中保存明文以保证功能可用。
